News Application Documentation
==============================

Welcome to the News Application documentation.

This Django application provides a role-based news platform where users
can read approved articles, journalists can create articles, editors can
review and approve articles, and users can subscribe to publishers or
journalists.

Features
--------

* Reader, editor, and journalist roles.
* Article creation and approval workflow.
* Publisher subscriptions.
* Journalist subscriptions.
* Newsletter management.
* REST API endpoints.
* Email notifications for approved articles.
